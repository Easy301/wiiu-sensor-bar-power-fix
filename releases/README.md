# Prebuilt Aroma plugins

Copy **one** of these to `sd:/wiiu/environments/aroma/plugins/` (or use `Launchers/`).

| File | Behavior |
|------|----------|
| `consolesensorbar-menu.wps` | Wired rear sensor bar **on Wii U Menu only** |
| `consolesensorbar-always.wps` | Bar **stays on** in menu, games, and apps (e.g. GamePad game while someone uses the bar elsewhere) |

**Author in Aroma:** easy301 · disable in WUPS: **L + D-Pad Down + Minus**

Do not install both `.wps` files at the same time.
